## 1. Flutter Geliştirme (En Sık Kullanacakların)

| Skill | Ne Zaman Kullan |
|-------|----------------|
| `ecc:flutter-build` | Build hatası aldığında |
| `ecc:flutter-review` | Yazdığın Flutter kodu gözden geçirmek için |
| `ecc:flutter-test` | Widget/entegrasyon testi eklemek için |
| `flutter-add-widget-test` | Belirli bir widget'a test yazmak için |
| `flutter-add-integration-test` | Tam akış testi (giriş → sayfa → çıkış) |
| `flutter-animations` | Animasyon eklemek istediğinde |
| `flutter-apply-architecture-best-practices` | Riverpod/go_router mimarisini uygulamak için |
| `flutter-build-responsive-layout` | Tablet/telefon duyarlı layout |
| `flutter-fix-layout-issues` | Layout overflow, pixel taşması gibi hatalar |
| `flutter-setup-declarative-routing` | go_router kurulumu/yapılandırması |
| `ecc:dart-flutter-patterns` | Dart/Flutter kalıpları hakkında rehber |

## 9. Ajanlar (Agent Tool ile çağrılır)

Skill'lerden farkı: ajanlar daha uzun, çok adımlı işler için — araştırma, mimari analiz, bağımsız alt görevler.

| Ajan | Ne Zaman Kullan |
|------|----------------|
| `flutter-expert` | Karmaşık Flutter mimarisi, performans optimizasyonu, platform kanalları |
| `mobile-developer` | Push bildirim, deep link, code signing, CI/CD kurulumu |
| `ecc:dart-build-resolver` | `dart analyze` hataları, pub bağımlılık çakışmaları, build_runner sorunları |
| `ecc:build-error-resolver` | TypeScript/genel build ve tür hataları |
| `ecc:flutter-reviewer` | Flutter kodu widget kalıpları, state yönetimi, performans tuzakları |
| `ecc:architect` | Yeni sistem tasarımı, ölçeklenebilirlik kararları |
| `ecc:code-architect` | Özellik mimarisi — hangi dosyalar, hangi sıra, veri akışı |
| `ecc:code-explorer` | Mevcut kodu anlamak, bağımlılıkları haritalamak |
| `ecc:planner` | Büyük özellik veya yeniden yapılandırma planlaması |
| `ecc:database-reviewer` | Supabase şema tasarımı, RLS politikaları, sorgu optimizasyonu |
| `ecc:performance-optimizer` | Darboğaz tespiti, paket boyutu azaltma, render optimizasyonu |
| `ecc:ui-ux-designer` | Ekran görüntüsü/mockup incelemesi, tasarım eleştirisi |
| `ecc:security-reviewer` | API key güvenliği, OWASP, veri güvenliği |
| `ecc:refactor-cleaner` | Ölü kod silme, kopyaları birleştirme |
| `ecc:tdd-guide` | Test güdümlü geliştirme, %80+ kapsam |
| `ecc:e2e-runner` | Uçtan uca test oluşturma ve çalıştırma |
| `ecc:docs-lookup` | Kütüphane/framework güncel dokümantasyonu (Context7 ile) |
| `ecc:code-reviewer` | Kalite, güvenlik, sürdürülebilirlik incelemesi |
| `error-detective` | Üretimdeki hata zinciri analizi, kök neden |
| `fullstack-developer` | Flutter + Supabase tam yığın özellik (DB → API → UI) |
| `Explore` | Hızlı kod arama — sembol, dosya, referans bulma |

## Hızlı Karar Akışı

```
Yeni özellik mi?        → ecc:plan (skill) → ecc:code-architect (ajan) → ecc:orch-add-feature (skill)
Build hatası mı?        → ecc:flutter-build (skill) / ecc:dart-build-resolver (ajan)
Layout sorunu mu?       → flutter-fix-layout-issues (skill)
UI beğenmedin mi?       → ecc:make-interfaces-feel-better (skill) / ecc:ui-ux-designer (ajan)
Test yaz mı?            → flutter-add-widget-test (skill) / ecc:tdd-guide (ajan)
Supabase/DB mi?         → ecc:database-reviewer (ajan)
Flutter+Supabase tam?   → fullstack-developer (ajan)
Bug kök nedeni mi?      → investigate (skill) / error-detective (ajan)
Kod anlama/keşif mi?    → Explore (ajan)
Performans mı?          → ecc:performance-optimizer (ajan)
```
